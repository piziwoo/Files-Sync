本地文件 / 文件夹与 WebDAV 服务器的双向同步工具，支持实时监控。

首次运行脚本，会自动在当前目录生成sync.json配置模板，格式如下：  
地址：[WebDAV服务器地址，如https://example.com/dav]  
账号：[WebDAV账号，匿名访问则留空]  
密码：[WebDAV密码，匿名访问则留空]  
被限制下载的后缀名“用、隔开”：[如exe、bat，限制这些后缀的文件下载]  
绕过后缀名“只能填一个，空白代表改为无后缀名再下载”：[如tmp，受限后缀文件会临时改为此后缀下载]  
格式：FS 同步码 文件夹路径 或 F 同步码 文件路径，下面输入每行一个  
示例：FS 123 D:\文件夹  

PS：  
1.由于某些webdav储存端的限制，无法下载exe等格式文件，可在被限制下载的后缀名此行加入被限制格式实现下载。  
2.代码基于Windows文件结构制作，移植其他平台还需些许修改。
